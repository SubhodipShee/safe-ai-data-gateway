What just happened?

  1. Detected emails, phones, Aadhaar (Verhoeff checksum), PAN, GSTIN (mod-36 checksum), UPI, bank details and API keys, even when disguised with Hindi/Bengali digits, invisible characters or look-alike letters.
  2. Recognised people's names with a small AI model running inside the gateway (offline), and addresses by their PIN code.
  3. Replaced each value with a tag. The same value always gets the same tag.
  4. Encrypted the real values with AES-256-GCM, using a separate key per session, and stored them for 24 hours.
  5. Restored the tags in the reply, so you see a normal answer while the AI never saw your data.
  6. Recorded what was caught in a SHA-256 hash chain with an Ed25519-signed head: editing or deleting any entry is detected.
